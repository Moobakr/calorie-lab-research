# Original project and research project

The project has two separate repositories so readers can distinguish the starting notebook from the research study.

| Repository | Purpose |
| --- | --- |
| [calories-burnt-prediction](https://github.com/Moobakr/calories-burnt-prediction) | Original notebook, unchanged, with a short explanation and link to the research. |
| [calorie-lab-research](https://github.com/Moobakr/calorie-lab-research) | Research question, controlled experiments, reliability findings, source code, reports and demo links. |

For a CV or application, link the research repository. The original repository provides context for the project's development.

The original notebook is restored from commit `20a980246b93e8590c5adf9a35625db5ea53cbb3`. Restoring its repository's current contents uses a new commit; earlier commits and published PR history are retained. The research repository also preserves the earlier research history and an archived notebook copy for comparison.

This separation changes repository organization and links. It does not train models, alter scientific results, recalibrate intervals or repeat the reserved test evaluation. Existing deployment/research verification records remain historical snapshots of their recorded revisions.
